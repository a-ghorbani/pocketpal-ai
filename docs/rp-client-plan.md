# RP-клиент (оффлайн): план

Ветка: `feature/rp-client-plan`. Сборка APK: Actions → "Build Android APK" → Run workflow.

## Что уже есть в форке (PocketPal)
- Оффлайн-инференс через llama.rn (GGUF).
- Поиск моделей на Hugging Face, список квантований.

## Что добавить для RP
1. Персонажи (как в Crushon): карточка с именем, описанием, первым сообщением, стилем речи.
2. Режимы ответа: Действие / Диалог / Описание.
3. Мир (лорбук): записи с ключевыми словами, активируются при упоминании.
4. Фильтр моделей: цензура / без цензуры, квантование (Q4_K_M, Q5_K_M, ...), размер.
5. API-режим: адрес, ключ, модель (OpenAI-совместимый), для онлайн-этапа.
6. Настройки генерации: temperature, top-p, max tokens, размер контекста, repetition penalty.
7. Пресеты: Креативный RP, Строгий диалог, Технический.
