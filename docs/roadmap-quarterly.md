## 📅 第一阶段：离线核心加固 (2026.07 — 2026.09)

### 主题：不依赖任何后端，先把本地体验做透

#### 🎯 1.1 数据备份与导出

**不搞云同步**。不给用户画饼，给实实在在的本地数据安全感。

**架构决策 (ADR-2026-001):**

```markdown
# ADR-2026-001: 本地优先的数据策略 — 导出/导入替代云同步

## Context
无后端服务器。用户换机或重装时数据丢失。

## Options
- A) Firebase Cloud Sync (需后端，放弃)
- B) 手动 JSON 导出/导入 (最简单，用户可控)
- C) P2P 同步 (WebRTC/Libp2p，复杂但更自动化)
- D) B + C 共存

## Decision
Option D: 默认走 B（手动导出/导入），留 C 接口给高级用户。
- 导出格式: 单文件 JSON (加密用 E2EE)
- 导出内容: 聊天记录 + Pal 配置 + 应用设置
- 支持: 手动导出 → 分享/存储 → 导入
- P2P 同步作为实验性功能，不阻塞发布

## Consequences
(+) 零后端成本
(+) 用户完全掌控数据
(–) 不如云同步方便，但这是免费项目的现实取舍
```

**关键交付**: 导出聊天记录 → 导出 Pal 配置 → 导入恢复 → 加密导出

```markdown
# ADR-2026-002: 纯客户端 IAP — 无收据校验服务器

## Decision
- iOS: StoreKit 2 (已有 `PaymentService`)
- Android: Play Billing 5/6 (已有 `AndroidIAPService` 框架)

## Consequences
(+) 零后端部署
(+) Android IAP 代码已写，仅需端到端联调
(–) 无法跨设备恢复购买（但免费项目可接受）
```

## 📅 第二阶段：语音与人机交互升级 (2026.10 — 2026.12)

### 主题：让离线对话真正"自然"

#### 🎯 2.1 语音输入 (STT) + 语音对话模式

**架构决策 (ADR-2026-003):**

```markdown
# ADR-2026-003: 本地优先的 STT

## Decision
- 首选: 本地 Whisper.cpp (通过 llama.rn 推理，完全离线)
- Fallback: 系统 Speech API (调用 iOS/Android 原生, 无需后端)
- 不需要自建云端 STT 服务

## Consequences
(+) 完全离线可用
(+) 零后端成本
(–) Whisper 模型 ~80MB 需用户下载
(–) 旧设备本地推理延迟偏高
```

**关键交付**: 语音输入按钮 → Whisper 识别 → 对话 → TTS 闭环

#### 🎯 2.2 联网搜索（客户端直连）

这不是"后端"——是客户端直接调用搜索引擎 API。用户自己决定是否配置 API Key。

**架构决策 (ADR-2026-004):**

```markdown
# ADR-2026-004: 客户端直连网络搜索

## Decision
- 作为 MCP Tool 实现 (复用 AgentRunner + TalentRegistry)
- 搜索后端: 支持 DuckDuckGo (免费无需 Key) + Google/Bing (可选用户 Key)
- 用户可选择关闭联网搜索（纯离线模式）
- 架构上不引入任何中间服务器

## Consequences
(+) 真正的零后端联网搜索
(+) DuckDuckGo 无需 API Key，开箱即用
(–) 搜索质量依赖第三方 API
(–) 用户需知数据会发往搜索引擎
```

## 📅 第三阶段：智能与知识增强 (2027.01 — 2027.03)

### 主题：从"对话"到"个人知识助手"

#### 🎯 3.1 知识库 / RAG 系统

**全本地方案**，不需要任何后端。

```markdown
# ADR-2026-005: 全本地 RAG

## Decision
- 文档解析: 本地 PDF/TXT/Markdown/网页
- Embedding: 本地 Nomic Embed Text (GGUF, 通过 llama.rn)
- 向量存储: SQLite + FTS5（纯本地文件）
- 检索: 混合检索 + 本地 Re-ranking
- 不依赖任何云端 Embedding API

## Consequences
(+) 完全离线，数据不出手机
(+) 零后端成本
(–) 大型文档索引慢
(–) 低端设备性能受限
```

**关键交付**: 文档导入 → 本地索引 → 对话中 @知识库 → 自动检索
